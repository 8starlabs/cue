---
title: Update Cue
description: Install a newer Cue release with Homebrew.
---

Update Homebrew's package list, then upgrade Cue:

```sh
brew update
brew upgrade 8starlabs/cue/cue
```

Cue does not update itself in the background. Run the Homebrew commands when you want to install a published release.

If Cue is already running, open Activity Monitor, select Cue, click the stop button, and choose **Quit**. Then open a new zsh session in Apple Terminal or the VS Code integrated terminal to launch the updated app through the zsh integration.

See [Install Cue](/docs/install/install-cue) for setup, or [Uninstall Cue](/docs/install/uninstall) to remove it.
