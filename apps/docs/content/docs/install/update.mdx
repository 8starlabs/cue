---
title: Update Cue
description: Install a newer Cue release with Homebrew.
---

In a zsh terminal, run:

```sh
cue-update
```

This updates Homebrew and Cue, restarts Cue, and refreshes the integration in the current terminal. Run it whenever you want to install the latest published release.

<details>
<summary>Updating from Cue 0.1.8 or earlier</summary>

Older releases don't include `cue-update`. Run this one-time update in zsh:

```sh
brew update && brew upgrade 8starlabs/cue/cue && \
  "$(brew --prefix)/opt/cue/Cue.app/Contents/Resources/CueRuntime/bin/stop-cue-processes.sh" --stop && \
  unset CUE_HOME CUE_HOME_AUTO_VALUE && \
  source "$(brew --prefix)/opt/cue/share/cue/zsh/cue.zsh"
```

</details>

<details>
<summary>Check your installed version</summary>

```sh
brew list --versions cue
```

</details>

See [Install Cue](/docs/install/install-cue) for setup, or [Uninstall Cue](/docs/install/uninstall) to remove it.
