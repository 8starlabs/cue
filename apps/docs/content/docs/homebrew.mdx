> **Not available yet:** the first matching GitHub Release archive has not been published. The formula is maintained in `Formula/cue.rb` in the [Cue repository](https://github.com/8starlabs/cue); there is no separate tap repository. Until a release archive is available, follow the [source install guide](/docs/getting-started).

The release package currently supports Apple Silicon Macs running macOS 13 or later. Homebrew installs Cue's Node.js dependency for you.

## Install

After the release archive is published, add the Cue repository as a tap. Since the repository is named `cue` rather than `homebrew-cue`, include its Git URL:

```sh
brew tap 8starlabs/cue https://github.com/8starlabs/cue.git
```

Then install Cue from that tap:

```sh
brew install 8starlabs/cue/cue
```

Homebrew prints a `source` command after installation. Add that line to `~/.zshrc` so Cue loads in new zsh sessions. The expected path is:

```sh
source "$(brew --prefix)/opt/cue/share/cue/zsh/cue.zsh"
```

Open a new Apple Terminal window. The first launch may ask you to allow Cue under **System Settings → Privacy & Security → Accessibility**. Allow it so Cue can place the popup next to the terminal caret.

## Update

Homebrew does not upgrade Cue automatically. Refresh its package information and upgrade Cue when a newer release is available:

```sh
brew update
brew upgrade 8starlabs/cue/cue
```

Then stop the old background app and open a new Terminal window to load the upgraded shell integration:

```sh
pkill -x Cue 2>/dev/null || true
```

The new shell session starts the updated Cue app from the Homebrew installation.

## Uninstall

Remove the Cue `source` line you added from `~/.zshrc`, stop the running app, then uninstall the formula and clear its temporary socket files:

```sh
pkill -x Cue 2>/dev/null || true
brew uninstall 8starlabs/cue/cue
rm -f "/tmp/cue-$(id -u).sock" "/tmp/cue-$(id -u).sock.cache"
```

If you also want to remove the local tap checkout, run `brew untap 8starlabs/cue`. Close existing Terminal windows after removing the zsh line; their current sessions have already loaded the integration. If you no longer use Node.js and Homebrew reports it is unused, `brew autoremove` can remove it. To revoke Cue's Accessibility permission, remove Cue from **System Settings → Privacy & Security → Accessibility**.
