Cue shows command and path suggestions as you type in Apple Terminal. The popup follows the caret, shows descriptions for the selected row, and stays out of the way when Terminal loses focus. Start with setup, then learn the keyboard controls and how command specs power suggestions.

Cue currently targets macOS, Apple Terminal, and zsh. Its command definitions come from Fig's open-source autocomplete catalog; Cue supplies the shell integration and native popup. The Homebrew formula lives in this repository, but the first release archive is not available yet.
