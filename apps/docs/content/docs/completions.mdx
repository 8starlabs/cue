---
title: Suggestions
description: How Cue completes commands, options, files, and folders.
---

Cue combines Fig command specs with filesystem-aware path completion. Suggestions update as you type.

## Command specs

The engine uses [`@withfig/autocomplete`](https://github.com/withfig/autocomplete) specs for commands, subcommands, options, descriptions, icons, and dynamic suggestions. For example, `git ch` suggests Git commands and `git checkout ma` can suggest branches.

Specs are bundled with Cue, so command suggestions work offline. For path-taking commands, Cue shows files and folders. Type `-` to filter for options.

## Paths

`cd` suggests folders from the current directory and supports nested paths and `../` navigation. Hidden folders appear when you type a dot. After a path is accepted, type a space to start another argument.

Other path-taking commands suggest matching files and folders. Path completion also works after redirection and common command separators.

## Current limits

Cue handles common pipes, separators, redirections, and quoted tokens. Complex shell expansion and substitutions may behave differently. See [Fig spec support](/docs/fig-spec-support) for details.
