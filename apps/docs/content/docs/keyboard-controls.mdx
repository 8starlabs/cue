---
title: Keyboard controls
description: Work through Cue suggestions without leaving the prompt.
---

Cue is designed to leave the command line in charge. The popup is a visual suggestion list; your shell buffer remains the source of truth.

| Key | Action |
| --- | --- |
| `↑` / `↓` | Move through the visible suggestions. |
| `Enter` | Accept the highlighted suggestion. After accepting a `cd` folder, Enter dismisses the next-level suggestions; press Enter again to run `cd`. |
| `Space` | Finish the current `cd` path. This closes its suggestions so Enter can run the command. |
| `Tab` | Insert the highlighted Cue suggestion. It does not print zsh’s raw completion list. |
| `Esc` | Close suggestions for the current input. Editing the input starts suggestions again. |
| `⌘I` | Switch the description between the side card and the bottom of the suggestion panel. |

For example, type `cd ` and accept a folder with Tab or Enter. Cue shows that folder’s contents; Enter dismisses those suggestions, and another Enter changes directories.

After a non-directory suggestion is inserted with Tab, Enter runs the completed command. Review the command before running it; Cue only fills the prompt and does not execute a suggestion on its own.
