---
title: Keyboard controls
description: Work through Cue suggestions without leaving the prompt.
---

Cue opens suggestions as you type and keeps the shell buffer as the source of truth. The popup follows the live caret, supports long lists, and disappears when Terminal loses focus, its window moves, or you press Escape.

| Key       | Action                                                                                                                                                |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| `↑` / `↓` | Move through suggestions. The list scrolls to reveal more rows when the selection reaches an edge.                                                    |
| `Enter`   | Insert the highlighted suggestion. Press Enter again to run the completed command. For `cd`, Enter first dismisses the next-level folder suggestions. |
| `Space`   | Start the next command argument and refresh its suggestions.                                                                                          |
| `Tab`     | Insert the highlighted suggestion without printing zsh’s raw completion list or running the command.                                                  |
| `Esc`     | Close suggestions for the current input. Editing the input starts suggestions again.                                                                  |
| `⌘I`      | Toggle the description between a separate card on the right and a row below the suggestions.                                                          |

For example, type `cd ` and accept a folder with Tab or Enter. Cue shows that folder’s contents; Enter dismisses those suggestions, and another Enter changes directories. The parent folder suggestion `../` is available once per path level, so accepting it does not create an endless chain of `../` suggestions.

Cue only edits the prompt. Review the completed command before pressing Enter to run it.
