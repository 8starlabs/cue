Cue bundles [`@withfig/autocomplete`](https://github.com/withfig/autocomplete) specs and uses the schema from [`@withfig/autocomplete-types`](https://www.npmjs.com/package/@withfig/autocomplete-types). Specs provide suggestions; Cue provides parsing and the native popup.

## Works in Cue

- Nested commands, aliases, descriptions, priorities, options, argument hints, and suggestions.
- Static and variadic arguments, option rules, templates, fuzzy filtering, and file/folder completion.
- Script and custom generators, including filters, triggers, output processing, and cache settings.
- Generated and local specs, plus bundled Fig, system, emoji, and badge icons.
- `insertValue` and `replaceValue`, live filtering, arrow-key navigation, and flexible descriptions.

Generators run locally in the current directory with the Terminal environment. Cue executes commands without an implicit shell; specs can explicitly request one.

## Not the Fig desktop runtime

Cue does not include Fig’s desktop runtime or other shell integrations:

- Fig React `previewComponent` previews and other app-specific UI components.
- Fig’s `Arg.debounce` scheduling and live refresh after an asynchronous generator finishes.
- Remote or SSH-aware completion execution; Cue currently runs generators on the Mac and supplies an empty SSH prefix.
- Fig’s complete shell parser and its Bash, Fish, and other terminal integrations. Cue targets zsh in Apple Terminal and the VS Code integrated terminal, with support for common pipes, separators, redirections, and quoted tokens.
- Fig’s selection history and recency-based ranking. Cue honors spec priorities but does not learn ranking from past selections.

Specs that rely on these features may behave differently. Cue currently supports zsh in Apple Terminal and the VS Code integrated terminal.
