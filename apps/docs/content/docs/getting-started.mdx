## Requirements

- macOS 13 or later
- Apple Terminal
- zsh
- Node.js 22 or later
- pnpm 10 or later
- Xcode Command Line Tools, to build the Swift app

## Install from source

Clone the repository, then run these commands from its root:

```sh
git clone https://github.com/8starlabs/cue.git
cd cue
pnpm install
pnpm build:app
```

This builds the completion engine and native app at `packages/cue/build/Cue.app`.

## Load the shell integration

In the same Terminal window, run:

```sh
source "$PWD/packages/cue/zsh/cue.zsh"
```

Keep the terminal working directory at the repository root when running this command. To load Cue automatically in future zsh sessions, add an absolute source path to `~/.zshrc`:

```sh
source "/path/to/cue/packages/cue/zsh/cue.zsh"
```

Replace `/path/to/cue` with the absolute path to your clone. Restart Terminal or run `source ~/.zshrc` to apply it. Sourcing the integration also launches Cue in the background.

## Grant Accessibility access

macOS may ask to let Cue control your computer. Allow Cue under **System Settings → Privacy & Security → Accessibility**. Cue uses this access to read Terminal window geometry and place the suggestion popup near the caret; it does not take keyboard focus away from Terminal.

## Try a few commands

Type `git ch`, `cd `, `code `, or `rm ` and wait for the suggestion panel; you do not need to press Tab to make it appear. `git ch` shows matching Git subcommands. `cd ` shows folders in the current directory, and accepting a folder shows its next level. `code ` and file-taking commands such as `rm ` can show matching files and folders. Continue typing to narrow the list.

## Update

Pull the latest code and rebuild from the repository root:

```sh
git pull --ff-only
pnpm install
pnpm build:app
```

When you build from Apple Terminal, the build replaces the running Cue app automatically. Open a new Terminal window after updating so zsh loads the latest integration; existing windows do not reload `~/.zshrc` automatically. If you build from another app, stop Cue first, then open a new Terminal window:

```sh
pkill -x Cue 2>/dev/null || true
```

## Remove

First remove the Cue `source` line from `~/.zshrc`, then stop the background app and clear its temporary socket files:

```sh
pkill -x Cue 2>/dev/null || true
rm -f "/tmp/cue-$(id -u).sock" "/tmp/cue-$(id -u).sock.cache"
```

Close existing Terminal windows to unload the shell integration. Then delete the repository folder from Finder or remove your clone's folder from another directory. You can also remove Cue from **System Settings → Privacy & Security → Accessibility**. Keep Node.js and Xcode Command Line Tools if other projects use them.

## Homebrew

Prefer Homebrew? See the [Homebrew guide](/docs/homebrew) for installation, upgrades, and removal. The formula is maintained in this repository at `Formula/cue.rb`; no separate tap repository is needed.
