## First release

- Live command suggestions for Apple Terminal and the VS Code integrated terminal when using zsh.
- Fig autocomplete specs for command, subcommand, option, argument, description, and icon suggestions.
- File and folder completions, including Git branches and contextual file icons.
- A native macOS popup with arrow-key navigation, Enter and Tab acceptance, Escape dismissal, and a shortcut to reposition the selected suggestion's description.
- Homebrew installation and documentation for setup, keyboard controls, updates, and removal.
