## Changed

- Kept suggestions more compact when they open above a prompt near the bottom of the terminal, and rechecked the panel size after each layout adjustment.
- Moved documentation-search loading feedback into the results list so the search field stays uncluttered.

## Fixed

- Reduced first-show popup height near the terminal's lower edge to keep it closer to the caret and leave more recent output visible.
